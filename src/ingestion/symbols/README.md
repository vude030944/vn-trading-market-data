Symbol universes to subscribe to. One symbol per line, UPPERCASE; blank lines and
lines starting with `#` are ignored (see `config/base.py::read_symbol_file`).

| File | Used for |
|---|---|
| `vn30.txt` | Seed list for trying things out — the 30 VN30 constituents |
| `ssi.txt`, `dnse.txt`, `tcbs.txt` | Generated by `scripts/fetch_symbols.py` |

Point at a file with `DNSE_SYMBOLS_FILE` / `TCBS_SYMBOLS_FILE`
(SSI subscribes by topic pattern and takes no symbol file).

Why a file rather than an environment variable: the universe is 1600+ symbols and
changes monthly. Editing a file and restarting is cheaper than editing a secret.
