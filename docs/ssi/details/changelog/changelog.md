# Changelog

Lịch sử phát triển và thay đổi của FastConnect API

## Version 3.0.0 (Current)

**Release Date:** February 24, 2026

### ✨ New Features

  * 🚀 **Trading APIs** \- Hoàn thiện bộ API giao dịch

    * Account Balance API
    * Order Management APIs
    * Portfolio APIs
    * PPMMR Account API
  * 📊 **Market Data APIs** \- Dữ liệu thị trường real-time

    * Securities information
    * Price quotes
    * Price boards
  * 🔌 **WebSocket Support** \- Kết nối real-time

    * Price streaming
    * Order updates
    * Account notifications

### 🔧 Improvements

  * ⚡ Performance optimization
  * 📝 Enhanced documentation
  * 🔒 Security improvements

### 🐛 Bug Fixes

  * Fixed rate limiting issues
  * Improved error messages
  * Fixed WebSocket reconnection
