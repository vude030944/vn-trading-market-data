# Giới thiệu

Chào mừng đến với FastConnect Docs – bắt đầu từ đây.

## FastConnect là gì?

**FastConnect** là một nền tảng kết nối dịch vụ tốc độ cao, được thiết kế để đơn giản hoá việc tích hợp API và quản lý luồng dữ liệu.

## Tại sao chọn FastConnect?

  * **Hiệu năng cao** – độ trễ tối thiểu < 10ms.
  * **Dễ tích hợp** – SDK cho Go, Node.js, Python.
  * **Bảo mật** – TLS 1.3, mã hoá end-to-end.
