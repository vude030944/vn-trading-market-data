# iFlash Open API

Chào mừng bạn đến với tài liệu kỹ thuật iFlash Open API. Xây dựng ứng dụng giao dịch tự động, dữ liệu thị trường thời gian thực và quản lý danh mục trên nền tảng TCBS.

## URL gốc

`https://openapi.tcbs.com.vn`

## Nhóm API

  * **1. Xác thực** — Trao đổi API Key lấy JWT token.
  * **2. Tài khoản** — Thông tin tiểu khoản.
  * **3. Tiền** — Chuyển tiền, nộp/rút ký quỹ.
  * **4. Chứng khoán cơ sở — Lệnh** — Đặt lệnh, sửa/huỷ lệnh, sổ lệnh, sức mua, tài sản cơ sở.
  * **5. Chứng khoán cơ sở — Thị trường** — Thông tin mã, giá, bảng giá và dữ liệu thị trường cơ sở.
  * **6. Chứng khoán phái sinh — Lệnh** — Tài khoản, vị thế, đặt/sửa/huỷ lệnh phái sinh.
  * **7. Chứng khoán phái sinh — Thị trường** — Thông tin mã, giá và dữ liệu thị trường phái sinh.
